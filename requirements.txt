# ========================================
# TROUBLESHOOTING COMMON ISSUES
# ========================================

# 1. MediaPipe Installation Issues:
#    - Ensure Python 3.9-3.11 (avoid 3.12 for now)
#    - Use 64-bit Python installation
#    - Try: pip install mediapipe==0.10.7 (specific version)
#    - Alternative: pip install mediapipe --no-deps (then install deps manually)

# 2. CUDA/GPU Issues:
#    - Install CUDA toolkit before PyTorch GPU versions
#    - Verify GPU compatibility: nvidia-smi
#    - Use CPU versions if GPU setup fails

# 3. Memory Issues:
#    - Use smaller models initially
#    - Enable model quantization (bitsandbytes)
#    - Monitor memory usage with psutil

# 4. Import Errors:
#    - Ensure virtual environment is activated
#    - Reinstall packages if corruption suspected
#    - Check Python path and module resolution

# 5. Network/Download Issues:
#    - Check firewall settings for HuggingFace access
#    - Use offline mode if models are pre-downloaded
#    - Configure proxy settings if needed
